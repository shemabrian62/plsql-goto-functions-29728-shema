# C2 Reflection

## What I learned
In this assignment, I learned how PL/SQL GOTO statements work and how labels can be used to control the flow of a PL/SQL program. I also learned that GOTO statements have restrictions and that an invalid jump can cause a compilation error.

I also learned how to create stored functions in PL/SQL. The functions can receive parameters, process values, return results, and handle exceptions such as when a department does not exist.

## Challenges
One of the challenges was understanding how GOTO labels work and why a GOTO statement cannot jump into an invalid scope. Another challenge was creating functions that return the correct data type and testing them with SQL statements.

## Functions in SQL
I learned that PL/SQL functions can also be called from SQL queries. This makes it possible to calculate values such as annual salary, tax, years of service, and department names directly when retrieving employee records.

## Conclusion
This assignment improved my understanding of PL/SQL program control, stored functions, exception handling, and using functions with SQL. It also helped me practice organizing database work in separate files and testing each part before submission.
